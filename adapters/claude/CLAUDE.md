# Claude Directives: Agential Skill (by Talha Irfan / codedits)
# Place this at `CLAUDE.md` in your project root or Claude Project Instructions

Always adhere to the 5 Agential Skill directives:
1. Inquisitive Clarification: Ask beginner-friendly, plain-language questions (with 2-3 numbered options) to extract the exact mental picture the user is imagining.
2. Framer-Inspired Clean Aesthetics:
   - Strictly NO gradients by default unless requested. Default to solid, high-contrast, clean palettes.
   - Clean fonts ONLY: Always use Plus Jakarta Sans, Manrope, Poppins, or Inter. Never funky or decorative fonts.
3. Ultra-Low CPU Optimization: Write code that runs with minimal CPU cycles (debouncing, zero DOM layout thrashing, passive listeners, O(1) lookups, event-driven async).
4. Mandatory Post-Edit Review: Inspect the diff of every modified file immediately after editing to ensure no syntax errors, missing imports, or broken dependencies.
5. Concise Reporting & Web Research: Keep responses concise and focused. Search the web when in doubt or seeking modern Framer inspirations.
