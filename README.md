### 💡 Why Agential Skill?

Standard AI models often overwhelm non-technical users with complex jargon, generate heavy code that causes browser fan spin & CPU lag, break existing code when editing files, and rely on outdated training memory.

**Agential Skill fixes all of that.** It enforces a disciplined 4-step workflow that guarantees clean, fast, reliable, and beginner-friendly software every time.

## 🧠 Persistent Session Memory (`context.md`)

Never re-explain your project again when restarting a chat or switching AI models:
- **Instant Catch-Up**: Every project running `agential-skill` maintains a root `context.md` containing the project's vision, chosen colors, fonts, border-radius tokens, completed components, and next milestones.
- **Cross-Model Continuity**: If you switch from Claude to Gemini, Cursor, or GPT-4o, the agent reads `context.md` on Turn 1 and continues building with 100% architectural consistency.

## 🎨 Framer-Inspired Design System & Minimal Roundness

Agential Skill enforces strict, modern design standards to ensure every generated UI looks like an award-winning site:

### 🚫 Strictly NO Gradients by Default
- Default to **clean, solid, high-contrast aesthetics**: deep solid obsidian (`#0a0a0c`), slate engineering (`#0b0f17`), or studio white (`#ffffff`).
- Accents use **crisp solid colors** (e.g. solid electric blue `#3b82f6` or emerald `#10b981`), avoiding muddy multicolor rainbow gradients unless the user explicitly requests one.

### 📐 Minimal Roundness (Anti-Pill / Anti-Bubble)
- **Buttons & CTAs**: Use minimal, sharp roundness (`border-radius: 6px` to `8px`). Strictly avoid oval pill shapes (`rounded-full` / `9999px`) unless requested.
- **Cards & Modals**: Use subtle, refined corners (`border-radius: 8px` to `12px`).
- **Badges & Tags**: Compact, clean metadata tags (`border-radius: 4px` to `6px`).

### 👑 Elite Navbars & Hero Sections
- **The Navbar**: Sticky/fixed at top, subtle 1px border (`rgba(255, 255, 255, 0.08)`), backdrop-filter blur (`16px`), clean logo, and minimal links.
- **The Hero**: The centerpiece of the application. Generous padding (`100px+ 0`), authoritative headline with clean typographic hierarchy, balanced subtitle, crisp minimal-roundness CTAs, and deliberate whitespace.

### 🏗️ Section Architecture & Immersive Viewport Scale (100vh–140vh Desktop)
- **Distinct Storytelling Sections**: Divide web applications into structured, focused sections (Hero, Showcase, Bento Matrix, Interactive Canvas, Proof, Pricing, Final CTA).
- **One Signature Premium Component Per Section**: Every section features a dedicated, high-tier showcase (e.g., sticky feature reveals, dynamic bento grids, interactive playgrounds, metric dashboards)—never generic, repetitive text cards.
- **Desktop Viewport Sizing (100vh, 120vh, 130vh, 140vh)**:
  - **Hero Stage**: `min-height: 100vh` (or `100dvh`) for full-viewport impact.
  - **Sticky Feature Showcase**: `min-height: 120vh` to `140vh` allowing sticky preview elements to pin gracefully while narrative cards scroll through.
  - **Bento Grid / Ecosystem**: `min-height: 100vh` to `130vh` for expansive, uncrowded layout breathing room.
  - **Metrics & Final CTA**: `min-height: 80vh` to `100vh`.
- **Fluid Mobile Responsiveness (PC + Mobile Coexistence)**:
  - Never enforce rigid `130vh`/`140vh` heights on mobile screens.
  - Gracefully adapt with `min-height: auto` or modern dynamic viewport units (`100svh`/`100dvh`), generous vertical padding (`padding: 80px 0` to `100px 0`), single-column stacked layouts, and zero overflow.
- **Visual Design Benchmarks**: See [`references/premium-section-benchmarks.md`](./references/premium-section-benchmarks.md) for 9 visual reference archetypes with exact component breakdowns and height targets.

### ✍️ Clean Fonts Only (Never Funky or Novelty)
- **`Plus Jakarta Sans`**: Default tech & modern SaaS.
- **`Manrope`**: Geometric luxury & agency styling.
- **`Poppins`**: Rounded, approachable, and balanced.
- **`Inter` / `Geist`**: Dashboard precision & clean interface typography.
- *Funky, cartoonish, decorative, or amateur display fonts are strictly banned.*

### ⏳ Paced Feature Delivery (Anti-Agent Exhaustion)
- The AI implements features in **focused, cohesive chunks** (e.g., Navbar + Hero first).
- After each chunk, it reviews its code, runs sanity checks, and pauses for user feedback rather than rushing to generate a 10-page site in one exhausted turn.

| :--- | :--- | :--- |
