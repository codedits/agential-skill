### 💡 Why Agential Skill?

Standard AI models often overwhelm non-technical users with complex jargon, generate heavy code that causes browser fan spin & CPU lag, break existing code when editing files, and rely on outdated training memory.

**Agential Skill fixes all of that.** It enforces a disciplined 4-step workflow that guarantees clean, fast, reliable, and beginner-friendly software every time.

## 🎨 Framer-Inspired Design System & Typography Standards

Agential Skill enforces strict, modern design standards to ensure every generated UI looks like an award-winning site:

### 🚫 Strictly NO Gradients by Default
- Default to **clean, solid, high-contrast aesthetics**: deep solid obsidian (`#0a0a0c`), slate engineering (`#0b0f17`), or studio white (`#ffffff`).
- Accents use **crisp solid colors** (e.g. solid electric blue `#3b82f6` or emerald `#10b981`), avoiding muddy multicolor rainbow gradients unless the user explicitly requests one.

### ✍️ Clean Fonts Only (Never Funky or Novelty)
- **`Plus Jakarta Sans`**: Default tech & modern SaaS.
- **`Manrope`**: Geometric luxury & agency styling.
- **`Poppins`**: Rounded, approachable, and balanced.
- **`Inter` / `Geist`**: Dashboard precision & clean interface typography.
- *Funky, cartoonish, decorative, or amateur display fonts are strictly banned.*

### 📐 Framer & Linear Craftsmanship
- 1px subtle borders (`rgba(255, 255, 255, 0.08)` on dark, `rgba(0, 0, 0, 0.08)` on light).
- Generous, balanced whitespace with strong typographical hierarchy.
- Purposeful, GPU-accelerated micro-interactions (60fps hover lifts).

## 🎯 Real-World Comparison: Standard AI vs. Agential Skill

| Situation | Standard AI Behavior ❌ | With Agential Skill ✅ |
| :--- | :--- | :--- |
| **Requirements** | Confuses you with technical jargon (*"Do you want SSR or CSR with Hydration?"*) | Asks simple, plain choices (*"Do you want pages to load instantly without a screen reload? (1) Yes (2) Standard"*)|
| **Performance** | Causes browser lag with heavy loops and animating `top/left` properties | 60fps GPU acceleration using `transform/opacity` with 0% idle CPU |
| **Editing Files** | Often deletes other functions or leaves unclosed tags that break the app | Mandatory self-review pass checks all imports, tags, and callers before replying |
